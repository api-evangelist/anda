# Anda

Anda ([andaafrica.com](https://andaafrica.com)) is an Angolan mobility and delivery company operating ride-hailing and courier services with motorcycles, electric motorcycles, and tuk-tuks. It runs a drive-to-own model that helps drivers own their vehicles through training (ANDA Academia), insurance, and maintenance support. Moto-taxi rides are fulfilled via the Yango app. Based in Talatona, Angola.

Backed by: speedinvest (invested 2025)

Note: Anda does not currently publish any public API or developer documentation. This profile captures verified company identity and domain-security posture only.
